How to read the animation

1. The tree begins with all points in one region.

2. At each step, it chooses the split with the biggest impurity reduction.

3. A split on x1 draws a vertical line inside that node's local rectangle. A split on x2 draws a horizontal line inside that local rectangle.

4. The shaded background shows the current predicted class over the plane.
